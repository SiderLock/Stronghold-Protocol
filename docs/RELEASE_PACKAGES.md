# 本 fork 的便携发布包

`v0.3.3-20p.1` 候选采用下述范围；这不改变旧版已经发布的附件。正式发布仍需维护者验收候选文案、文件与校验结果。

## 平台与启动

| 包的后缀 | 目标机器 | 启动入口 |
|---|---|---|
| `Windows-x64.zip` | Windows 64 位 x86 | 双击 `启动游戏.bat` |
| `linux-x64.tar.gz` | Linux x86-64，需兼容包内官方 Node 二进制 | `bash 启动游戏.sh` |
| `darwin-arm64.tar.gz` | macOS Apple Silicon | `bash 启动游戏.sh` |
| `darwin-x64.tar.gz` | macOS Intel | `bash 启动游戏.sh` |

每个包都自带对应平台的 Node.js 22.23.3、Node 许可证和生产依赖，无需另装 Node 或运行 npm install。解压整个目录后启动，不要只复制启动脚本。浏览器打开本机服务；启动脚本不自动下载或提取游戏素材。端口、局域网与防火墙设置沿用 [部署说明](DEPLOY.md)。

“开箱即用”指自带运行环境与上游完整包的素材，**不是附带本分支演示中的全部时装与自提取资源**。随机时装使用当前安装实际拥有的资源；缺少可选素材时保留默认模型或简化画面。本机提取并生成相应索引后，再重启本机服务读取。连接其他人的服务器通常只需要浏览器。

## 素材来源与排除规则

美术、音频、字体及配套素材索引仅直接取自作者上游 `v0.3.3` 的原始完整包：

- 来源：[Stronghold-Protocol-v0.3.3.zip](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.3)。
- 完整归档 SHA-256：`1bfc651096ff4c44b76296717bd605220b5204714722832140a3d407153cd2be`。
- 只允许其中的 `public/assets/`、`public/fonts/` 普通文件，以及原包的 `data/assets.json`、`data/local-assets.json`、`data/local-fx.json`。逐文件记录来源与 SHA-256，不从维护者本机同名目录取替代文件；配套索引一起保留，避免引用仅存在于本机的素材。
- 上游原包自带部分 `public/assets/local/` 特效、场景及模型，按本次「仅上游现有素材」的要求保留；目录名 `local` 本身不能判定文件属于我们。本分支自行提取或新增的同路径文件不得覆盖它们。
- 排除本机 `data/local-skins.json` 及其他未经上游归档核验的素材索引、个人时装、特效 / 场景输出、私人记录、公告、运行配置、原始报告、缓存或其他服务文件。
- 只生成四个平台运行包和校验说明，**不生成或发布独立素材包**。

上游收录不等于获得使用或再次分发许可。游戏素材仍可能涉及侵权风险；自行提取也必须遵守权利人的授权与适用条款，不能把非商业用途或署名当成免责。请阅读 [NOTICE](../NOTICE.md) 和[本地提取参考](LOCAL_ASSET_EXTRACTION.md)。游戏素材不适用本项目代码的 GPL，Node、依赖库及 Spine Runtime 另有各自许可。

## 提取文档与包内文件

包根包含 `README-开箱即用.md`、更新说明和许可证；游戏在 `app/`，运行时在 `node/`。主要文档：

- `app/docs/LOCAL_ASSET_EXTRACTION.md`：Python 环境、皮肤图片 / 模型 / 特效提取与核验。
- `app/docs/REFERENCES.md`：参考开发者、功能思路、冻结版本与采用范围。
- `app/docs/RELEASE_PACKAGES.md`：本页。
- `app/docs/releases/v0.3.3-20p.1.md`：简明更新内容及素材边界。
- `RELEASE.json`：候选版本、源码提交、目标平台和上游归档来源。
- `PACKAGE-MANIFEST.json`：包内实际文件的大小与 SHA-256。

提取工具在 `app/tools/local-extract/`；输出留在使用者本机。素材包、截图或模型文件不能代替提取说明对外分发。

## 准备与核验

维护者使用 `tools/release-candidate.py` 准备候选，复用既有玩家文件白名单与文档处理；不使用会整树复制本机素材的旧便携脚本默认流程。工具要求明确的源码提交、经校验的上游归档和固定哈希的四平台官方 Node 归档，输出到专用新目录，不覆盖现有目录，不自动推送、打 tag、创建 Release 或上传附件。

核验包括来源归档哈希、来源路径与文件哈希、本机提取输出的排除、依赖及许可证、归档 CRC / 哈希、脚本权限和本机可运行目标的启动检查。上游素材及配套索引的文件集合必须完整一致；缺项、额外本机文件或同路径替换均拒绝。macOS 的实机启动不能由 Windows 或 Linux 的结构检查替代；实际结果单独写入候选核验清单。

候选目录额外生成简明 `ReleaseNotes.md` 与完整 `ServerAnnouncement.md`：Release 概括上游与本分支变化，服务器公告完整保留上游 0.3.3 / 0.3.2 日志及贡献者署名，再追加本分支更新。公告稿不放入运行包，也不因生成而自动发布；服务器实际更新后再发布公告，不能提前声称新功能已经上线。
