# 当前素材优先与玩家授权缓存

2026-10-22，`feat/skin-enhance`；用户确认见 [D042](DECISIONS.md#d042)，本地过程记录 DEV-20261022-09。此项是浏览器素材文件复用，不保存 WebGL 纹理、Spine 实例或整个渲染器。

## 玩家入口

设置 → 素材存储 → **允许本地缓存与后台补齐**，默认关闭；结算页右上角也有「素材存储」入口，使用同一授权界面。提示说明后台下载与最多 2 GiB 的占用，选择保存在本浏览器。可随时关闭，或点击「关闭并清理对局缓存」删除这一缓存；导入包与原有校验预缓存保留。清理完成会通知本站其他标签页停止补齐并关闭此项设置。

需要 HTTPS / localhost、Cache Storage 和支持此能力的模块 Service Worker。旧 Worker 仍在使用时，沿用现有空闲升级保护；对局不被强制刷新，界面提示重新打开。存储可能被浏览器回收，原有「申请持久保存」按钮仍单独使用。不支持或存储失败时按原有方式游玩。

## 加载顺序与资源预算

- 每个客户端从第一回合起，独立读取自己的私有布局、手牌、临时区、当前皮肤 / DIY / 替身、技能与装备图标、当前关卡和下一波敌人。商店只提前取展示图片，不提前解析全体角色模型。
- 图片、Spine、场景二进制与特效库的实际前台请求优先；其未完成时不启动补齐。当前需要的文件最多两个并发；全部就绪并空闲 600 ms 后，后台一次取一个其余画面文件。新增购买或皮肤内容会中止可选下载并让当前内容先行。
- 后台只消费文件字节，不把完整角色 / 特效目录解码为图片、骨骼或 GPU 对象。已有导入包、校验预缓存和普通 HTTP 缓存继续复用，授权缓存优先于重复联网；队列不自行导入文件或取得严格准入资格。
- 隐藏页面、断网、浏览器省流量、2G 网络暂停可选队列；退出对局或关闭授权也暂停。网络 / 可见性恢复后可重试。单文件 30 秒无传输进度取消；继续传输的慢请求允许完成。
- 自动队列走普通不可变素材请求，只有服务器小摘要明确允许且总带宽 / 单客户端均不限速时才补齐，15 秒更新一次摘要。有限额、关闭或未知状态不绕过原下载预算。带宽紧急状态也暂停。既有手动受限补齐入口与局内维护保护保持原规则。

`assetPlan.js` 根据现有清单生成 URL，`assetPriority.js` 调度，`assetPreload.js` 在已就绪对局中懒加载并协调。不加全房等待，不发新的房间协议，不下载音频或字体。初次实际技能需要的特效仍由现有特效库按需解析；全目录仅在后台保存原文件。

## 缓存边界

2026-10-23 补充：所有逐文件补齐使用独立的无进度截止机制，即使 Fetch / Service Worker 的响应不处理 abort，
读取也会退出；取消流本身的等待不会占住队列。自动预取沿用 30 秒，显式下载沿用 60 秒无进度预算，持续传输不受总耗时限制。
预缓存 Worker 将暂时失败文件排至健康文件之后再重试，最多两次；用尽后仍保留并报告已校验文件，原页重试只补缺项。
暂停、配额、目录过期与服主关闭 / 应急时，先取消并收完本轮并发任务再接受下一操作。
服务器按响应隔离至多 8 KiB 的待读缓冲，不让一个慢文件占住全局调度；无进度的准备、读取、背压和收尾名额会回收。
详见 [下载约定](../ASSETS.md#player-initiated-predownload)，本地 DEV-20261023-02。

单一 `asset-cache-sw.js` 在玩家同意后使用 `sp-render-assets-v1`。只接受本站 `/assets/~<16 位 hash>/` 的画面文件，不接收可变路径、查询参数、HTML、脚本、API 或游戏状态。按完整不可变 URL 复用，版本 hash 改变即重新获取，不以旧图替代。已有经过验证的导入包优先。

最多 2 GiB、单文件最多 32 MiB、同时最多两份响应副本；串行写入 / 清理，只保存完整 200 或覆盖整个文件的 206。配额不足、单文件越界或存储失败通知页面停止后台补齐，前台请求仍返回。清理取消尚未完成的副本读取并使旧写任务失效，防止清理后回填。缓存只代表可复用文件，不充当完整 SHA 校验或严格入场证明。多版本会累计占用，达到上限后由玩家清理；当前没有自动 LRU。

本机原始清单静态盘点约 942 MiB / 33,978 个不同画面 URL，最大约 8.5 MiB、路径缺项 0；这不是服务器实际合并别名后的下载量或全设备占用承诺。下一次仍需在当前页面建立 GPU 对象，不能承诺零首帧耗时。

## 验证与限制

定向缓存 / 优先队列测试覆盖默认拒绝写入、显式授权、当前内容屏障、抢占、禁用 / 清理、版本隔离、Range、导入复用、上限和下载未完成时清理。Edge 157 实际应用中创建独立模拟，完成简报与策略，首回合购买角色，确认优先队列完成；新文档关闭普通 HTTP 缓存后从授权缓存读出 56,617 B，服务器没有新增该文件请求。结算组件使用只读结果夹具检查小屏入口与清理，不将夹具当成完整打通结算。证据在项目忽略目录 `.cache/asset-priority-edge/`。
