## 玩家可控制的行为

设置新增 **帧率上限：30 FPS / 60 FPS / 不限**，默认不限以保持旧配置行为；选择保存在本浏览器，立即应用于战场及小人预览。不改变固定步长的战斗计算、游戏速度或结算。实际帧率仍受设备性能与显示刷新率限制。30 FPS 的自动负载判断使用相应帧预算，避免主动限帧触发降分辨率。开发测量页支持 `?fps=30` / `60`，采样跟随实际绘制 ticker。

设置 → 画面质量下方增加 **自动调整渲染分辨率**，默认开启并保存在本浏览器。用户显式关闭后一直保持关闭，刷新不会重新开启。开关立即作用于当前棋盘，不需要重新开局。

仅在触控为主且没有精细指针的设备上，沿用已有连续慢帧负载判断和恢复滞后：负载等级 1 / 2 / 3 将角色及棋盘画布的 DPR 上限降为 1.5 / 1.25 / 1；恢复后逐步升回所选画质。上限始终不超过设备 DPR 与高 / 中 / 低画质的原上限。关闭开关立即恢复所选画质的上限；桌面不受这项分辨率调整影响。

这会在压力较大时降低棋盘与角色的细腻程度；DOM 界面文字、布局、棋盘投影和触控坐标保持原样。不自动关闭特效、不更改用户选择的画质档位。原有移动端「自动」特效使用精简档的行为保留。

## 特效绘制与采样维护（2026-11-05）

基线为 `dev@9ebdb0fe`。本轮处理相邻材质合批、静态 UV 旋转和粒子临时缓冲区，并修正开发性能页的采样时机。

| 环节 | 当前实现 |
|---|---|
| 材质合批 | 编译时根据 shader 变体、uniform、纹理及混合 / 深度 / 剔除 / 颜色写入状态生成等价签名。先完成现有 Unity 排序，再合并同一 pass 内几何连续、类型及网格子部分一致的相邻项。每个材质保留自己的名称与记录，带动画覆盖值的项单独绘制 |

| 粒子缓冲区 | 距离排序复用深度数组，带状轨迹复用排序索引，轨迹与残留轨迹复用位置数组。容量不足时扩容，读取范围按当前有效数量限定 |
| 性能采样 | ticker 优先级为 −27，接在 Pixi 绘制 −25 和绘制耗时探针 −26 之后，排除首个不完整帧。特效数量、粒子数、绘制调用、三角形及几何上传字节报告窗口均值和峰值 |

## 特效加载与编译复用（2026-11-05）

## 特效 GPU 状态与参数复用（2026-11-05）
