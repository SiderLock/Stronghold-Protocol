# v0.4.0-20p.3：规程·序列Ⅰ、上游 0.4.0 同步与二十人适配

本版接在 `v0.3.4-20p.3` 之后，合入上游 **0.4.0**（2026-11-15）和它 `dev` 的第 84 轮（`c7cea5a9`）。
二十人容量、固定分组、并行轮选、多轮联防、私人自选库存、组内真人优先都保留。

标签说明：`v0.4.0-20p.1` 和 `v0.4.0-20p.2` 已指向更早的提交，所以本次用 `v0.4.0-20p.3`，
让源码下载与便携包对应同一个提交。

## 更新日志

### 上游更新概括

- **第五个官方版本「规程·序列Ⅰ」**（`act3autochess@V3_1`，大厅默认）：37 名干员、26 个盟约、5 格装备区、策略指令、每局随机抽选的盟约、官方整块战场与赛季外观；单人是官方的分级（极速模拟和规程等级 1 至 20）。
- **规程数值按官方记录修正**：「攻击力提升至」在减防前结算；收入 `min(3 + round, 11)`；聚合改为生命回复速度光环；莱塔尼亚召唤物持有禁疗；盐坨子炮能载客并续路；地图地形特效按可见格压深。
- **界面**：盟约圆盘按官方录像改版；匹配内队友速查浮窗；设置按分类组织，可跨类搜索；名片干员可选任一官方时期的干员。
- **素材与表现**：分段场景、盐坨子炮原版模型与炮击动画、官方特效、官方界面主题（卫戍协议终端官方贴图、乌萨斯齐心团）、时装独立语音、干员朝向。
- **其他**：规程英文文本（Terra Archive 非官方翻译）、CN 2.7.91 的新干员与模组，以及一批规则、AI、素材缓存和稳定性修复。

### 本分支新增与修复

- **二十人容量与分组**：房间容量可选 4、8、10、16、20，六人起按实际人数分组。各组独立共享干员与装备库存，策略和机变按组并行、组内轮选，组内手动真人优先。
- **多人联防**：按组数扩展联防，最多五轮，可逐轮投票取消；领袖血池、退场缩放和搭档分配适配多人，保留全房支援与跨组信标。
- **私人自选库存**：自选编队按基础数量发放，不乘合作或分组倍数；规程联机沿用同一规则。
- **房间协作**：房间列表、快速匹配、目录观战、局内聊天、换座、房主转让、队友申请重刷。
- **素材与皮肤**：召唤物随主人换装、皮肤独立语音槽、穿搭导入导出、本机客户端提取的朝向与动作元数据；缺素材时按原逻辑回退。
- **网络与运维**：紧凑协议与压缩、背压状态合并、P2P 公共状态转发、连接诊断、素材预缓存与素材包导入、公告与带宽保护。
- **性能与插件**：场景预处理、AI 预演进程池、资源回收、骨骼热路径优化；插件工作台与 0.3.x 插件约定不变。

以上概括自上游 [0.3.3 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.3)和 [0.4.0 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.4.0)。感谢 sganggs 与上游贡献者；本分支的取舍依据见[上游同步记录](../development/UPSTREAM.md)和[已确认决定](../development/DECISIONS.md)。

## 验证与已知边界

- GitHub CI 在合入前的 `dev` 上通过：golden 全量、工具检查、Node 24 守卫、ubuntu 与 windows 各 4 个测试分片、Python 提取器语法，全部 success。
- 二十人规则与五版本内容跑过本机完整回归；本机环境相关的失败项（`python3` 占位符、Node 24 插件原生退出、素材缓存、符号链接权限、既有 0.8 Mbps 压力用例）单列，没有算作通过。
- 候选包逐文件校验：四个平台各 46,185 或 46,186 个文件；包内素材 38,745 个文件与上游归档逐字节一致；Windows 包解压后用包内 Node 启动，`/healthz` 与特效索引都返回 200。
- macOS 两个包只做了归档、架构和权限核验，未实机启动；Linux 同样只有结构核验。二十人真人长局、极低共享带宽、手机真机表现仍保留各自的验证边界。

## 下载与素材边界

- 提供 **Windows x64、Linux x64、macOS Apple Silicon、macOS Intel** 四种便携包，各带 Node.js 22.23.3 与生产依赖；解压后运行包根的启动脚本。校验值见 `SHA256SUMS.txt`。
- **素材只取自已核验的上游 v0.4.0 完整包**，包括它自带的官方特效、场景和配套索引。本机提取或替换的时装、模型、3D 场景不进包，也不另外发布素材包。
- 建议解压到新目录再迁移配置。升级服务器前先等正在进行或断线保留的对局结束，不要直接覆盖运行中的服务。更新完成后刷新页面加载新版本。
