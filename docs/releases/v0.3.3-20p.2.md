# v0.3.3-20p.2：房间、棋盘与干员调配界面适配

本次更新改善不同屏幕比例下的界面显示，尤其是手机横屏、平板和小窗口。游戏规则、素材和个人配置不因本次更新改变。

## 更新内容

- **房间与玩家标识**：调整多人等待房卡片、头像、姓名和状态的排布；优化小屏人数按钮、单人房顶部和局内队伍栏的显示与触控。
- **准备与对局画面**：收紧手机横屏的商店和羁绊区，为准备棋盘留出更多空间；调整平板和接近 4:3 窗口的棋盘避让，避免队伍栏遮挡操作区域。简化渲染画面也改善了棋盘的空间利用。
- **开局信息**：提高短屏幕上领袖、战场、敌人和盟约说明的可读性。
- **干员调配**：卡片视图的宽度随可用高度调整，改善不同设备上的立绘比例；短横屏皮肤缩略图更紧凑，干员和外观名称跟随文字大小设置。

## 下载与覆盖更新

本次只提供一个增量 ZIP，不包含完整游戏、运行时、素材或依赖。**只适用于本分支 [v0.3.3-20p.1 四平台便携包](https://github.com/SiderLock/Stronghold-Protocol/releases/tag/v0.3.3-20p.1)**；全新安装或从其他版本升级，请先安装该版本的对应完整包。Git 源码安装请使用 Git 更新，不要把此增量包覆盖到源码目录。

1. 等待当前对局和断线保留对局结束，停止本机游戏服务。建议先备份原便携包目录，尤其是自己的配置、素材和存档。
2. 将 `Stronghold-Protocol-v0.3.3-20p.2-update.zip` 解压到临时目录，选择与旧包一致的目录：`Windows-x64`、`linux-x64`、`darwin-arm64`（Apple Silicon）或 `darwin-x64`（Intel）。
3. 把**所选平台目录里面的全部内容**复制到原便携包根目录，也就是能看到 `app`、`node` 和启动脚本的目录。合并同名文件夹并替换同名文件；不要将平台目录本身套进旧包。
4. 按原方式启动：Windows 双击 `启动游戏.bat`；Linux / macOS 运行 `bash 启动游戏.sh`。首次启动会校验更新后的程序文件；如提示版本不符或文件缺失，请确认使用的是上述旧版完整便携包，并重新完整覆盖。

首次启动完成后，`app/UPDATE.json` 会改名为 `app/.update-applied.json`；包根的 `PACKAGE-MANIFEST.json` 记录的是覆盖后、首次启动前的文件清单，运行时生成的文件不在其中。

Windows 可用资源管理器复制，并在提示时选择替换。macOS / Linux 建议用终端合并，避免图形界面将整个 `app` 文件夹替换掉。例如先将 ZIP 解压到临时目录，再执行（将平台名和安装路径改成自己的）：

```bash
cp -R /临时目录/darwin-arm64/. "/原便携包目录/"
```

包中不会覆盖 `app/public/assets/`、`app/public/fonts/`、`app/data/`、`app/runtime/`、本地配置或 `node/`。如果自行修改过本次涉及的界面程序文件，覆盖会替换这些同名文件。直接连接他人服务器的玩家无需下载此包，服务器更新后刷新页面即可。

四版本、五种语言和多种屏幕尺寸已用桌面 Edge 模拟验证；尚未在 iOS / Android 真机或 Safari 上验收。校验值见 Release 附件 `SHA256SUMS.txt`。
