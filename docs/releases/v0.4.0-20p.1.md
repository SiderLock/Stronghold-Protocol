# v0.4.0-20p.1：规程·序列Ⅰ、上游 0.4.0 同步与二十人适配

本版从 `v0.3.4-20p.3` 升级，完整同步上游 **0.4.0**（2026-11-15），并跟随其 `dev` 到第 84 轮（`c7cea5a9`）。
二十人容量、固定分组、并行轮选、多轮联防、私人自选库存和组内真人优先全部保留。

## 更新日志

### 上游更新概括

- **第五个官方版本「规程·序列Ⅰ」**（`act3autochess@V3_1`，大厅默认）：37 名干员、26 个盟约、5 格装备区、策略指令、每局随机抽选的盟约、官方整块战场与赛季外观；单人是官方的分级（极速模拟与规程等级 1–20）。
- **规程数值与机制回到官方记录**：「攻击力提升至」在减防前结算、收入 `min(3 + round, 11)`、聚合改为生命回复速度光环、莱塔尼亚召唤物持有禁疗、盐坨子炮的载客与落地续路、地图地形特效与可见格深度。
- **界面**：盟约圆盘按官方录像改版，匹配内队友速查浮窗，设置按分类组织并可跨类搜索，名片干员可选任一官方时期的干员。
- **素材与表现**：分段场景、盐坨子炮原版模型与炮击动画、官方特效、界面主题（卫戍协议终端官方贴图、乌萨斯齐心团）、时装独立语音与干员朝向。
- **其他**：规程英文文本（Terra Archive 非官方翻译）、CN 2.7.91 的新干员与模组，以及一批规则、AI、素材缓存与稳定性修复。

### 本分支新增与修复

- **二十人容量与固定分组**：房间容量可选 4 / 8 / 10 / 16 / 20，六人起按实际人数分组；各组独立共享干员与装备库存，策略与机变并行、组内轮选，保留组内手动真人优先（D004）。
- **多人联防与领袖适配**：按组数扩展联防，最多五轮并可逐轮取消；领袖血池、退场缩放与搭档分配适配多人，保留全房支援和跨组信标。
- **私人自选库存（D028）**：自选编队按基础数量发放，不乘合作或分组倍数；规程联机沿用同一规则。
- **房间协作**：房间列表、快速匹配、目录观战、局内聊天、换座与房主转让、队友申请重刷。
- **素材与皮肤**：召唤物随主人换装、皮肤独立语音槽、穿搭导入导出、本机客户端提取的朝向与动作元数据；缺少素材时按原逻辑回退。
- **网络与运维**：紧凑协议与压缩、背压状态合并、P2P 公共状态转发、连接诊断、素材预缓存与素材包导入、公告与带宽保护。
- **性能与插件**：场景预处理、AI 预演进程池、资源回收与骨骼热路径优化；插件工作台、外观与玩法插件沿用 0.3.x 约定。

以上概括自上游 [0.3.3 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.3)和 [0.4.0 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.4.0)。感谢 sganggs 与上游贡献者；本分支改动与取舍依据见[上游同步记录](../development/UPSTREAM.md)与[已确认决定](../development/DECISIONS.md)。

## 下载与素材边界

- 提供 **Windows x64、Linux x64、macOS Apple Silicon、macOS Intel** 四种便携包，均自带 Node.js 22.23.3 与生产依赖；解压后运行包根的启动脚本。校验值见 `SHA256SUMS.txt`。
- **素材仅取自已核验的上游 v0.4.0 原始完整包**，包括上游自带的官方特效、场景及配套索引；不加入我们本机新增、替换或自行提取的时装、模型、3D 场景与其他素材，也不另发独立素材包。
- 建议解压到新目录再迁移配置。服务器升级请先等待正在进行或断线保留的对局结束，不要直接覆盖运行中的服务。完成更新后刷新页面加载新版本。
- Windows 与 Linux 的实际启动、macOS 的归档 / 架构 / 权限核验分别列入候选验收清单；macOS 尚未实机验证。二十人真人长局、极低共享带宽与手机真机表现仍保留各自的验证边界。
