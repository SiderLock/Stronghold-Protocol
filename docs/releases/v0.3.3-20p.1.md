# v0.3.3-20p.1：四版本支持、随机时装与联机优化

本版从 `v0.3.1-20p.2` 升级，完整同步上游 **0.3.2～0.3.3**，并保留本分支的 20 人容量、固定分组与并行轮选。

## 更新日志

### 上游更新概括

- **四个官方版本可切换**：支持第一期上半／下半、第二期上半／下半；大厅可选择版本，房间可投票切换，相关配置与统计按版本处理。历史版本仍标为预览，部分细节尚有推算。
- **大厅、房间与调配界面更新**：新增名片展示、干员调配卡片视图，以及自选大厅背景与音乐；优化开局流程、对局顶栏、手机横屏、大字号与版本投票的显示。
- **战斗与 AI 修正**：修复多名干员的技能触发、对空攻击及伤害结算问题，调整昆图斯等敌人的技能与普攻衔接；改进 AI 的阵容搭配、资金使用和首领回合站位。
- **开局重刷与隐秘核心**：任意在座真人可直接发起或取消重刷投票，仍需全员同意；隐秘核心开局重新随机搭档与左右位置。
- **0.3.3 热修复**：修正第一期商店装备空栏显示、满整备区与场上干员互换，以及切换版本或重连后装备图标沿用旧版本的问题。
- **稳定性维护**：改进插件对局、素材导入与缓存、断线重连和状态同步，减少重复加载及部分异常情况。

### 本分支新增与修复

- **AI 随机时装**：每局开局为有可用时装的干员随机搭配，同局所有 AI 共用一份配置。
- **玩家随机换装**：干员调配增加皮肤随机功能，可选择「固定本次随机内容」或「每局都随机」；重连和本局开局重刷保留已抽取的搭配。
- **倒地与旋转动作修复**：修复魔王「追悼」倒地后小人消失，保留复活与迟到加载的正常显示；补齐水遁忍者旋转技能的开始、循环和收招，并同步失衡打断。
- **多人同步优化**：减少 20 人状态广播中的重复处理和客户端临时复制，保持消息内容与游戏规则不变。实测收益因设备和场景而异，不等同于整体帧率提升。
- **20 人适配延续**：将四版本内容与本分支既有分组、轮选、联防和领袖规则衔接，保留原有容量配置与协作功能。

随机时装只使用当前服务器已经安装的资源；未安装对应时装时沿用默认外观，不会自动下载本分支的私有素材。

以上概括自上游 [0.3.2 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.2)和 [0.3.3 更新日志](https://github.com/sganggs/Stronghold-Protocol/releases/tag/v0.3.3)。感谢 **sganggs 与上游贡献者**，以及提供多人分支基础的 **LongQianChen（龙千尘）**；其他参考与致谢见[来源说明](../REFERENCES.md)。

## 下载与素材边界

- 提供 **Windows x64、Linux x64、macOS Apple Silicon、macOS Intel** 四种便携包，均自带 Node.js 22.23.3 和生产依赖；解压后运行包根的启动脚本。校验值见 `SHA256SUMS.txt`。
- **素材仅取自已核验的上游 v0.3.3 原始完整包**，包括上游自带的官方特效、场景及配套索引；不加入我们本机新增、替换或自行提取的时装、模型与其他素材，也不另发独立素材包。
- 建议解压到新目录再迁移配置。服务器升级请先等待正在进行或断线保留的对局结束；不要直接覆盖运行中的服务。完成更新后刷新页面加载新版本。
- Windows 与 Linux 的实际启动结果、macOS 的归档／架构／权限核验分别列入候选验收清单；macOS 尚未实机验证。历史版本预览、极低共享带宽和手机真机表现仍保留各自验证边界。
