# v0.3.4-20p.2（预发布）：特效分档、素材修复与渲染优化

本次为二十人分支的开发线预发布，接续 `v0.3.4-20p.1`，同步上游 `dev` 至
`e017558ac6b5f87f188c6feacf6a9f6597461c3e`。应用版本仍显示 `0.3.3`；本次不提供便携包。
源码运行方式和本地素材准备见 [部署说明](../DEPLOY.md) 与 [本地提取说明](../LOCAL_ASSET_EXTRACTION.md)。

## 玩家可见的变化

- **官方特效增加高、中、低三档及关闭。** 原「完整」对应高、原「精简」对应中，已有设置继续生效。
  低档进一步减少普通特效和粒子发射，并保留中档可见的单粒子提示。电脑默认高、触控设备默认中。
  玩家可在设置中单独调整官方特效，无需同时改变画质或帧率。
- **补齐新干员的特效与语音。** 修复冻河、国度、塔露拉的技能特效索引、基础语音和战斗音效缺项；
  三名干员的九个技能已完成浏览器实际战斗验证。
- **接通时装独立配音。** 按官方映射补齐 20 套已安装时装的 924 个独立音频，其他时装沿用基础配音回退。
  三名新干员与这些时装共 1050 个音频已通过浏览器正式加载链路解码。
- **减少渲染中的重复工作。** 合并相邻等价材质绘制，共享静态变换、复用粒子缓冲区和 GPU 参数，
  并合并同一特效的并发编译、优先加载绘制依赖，减轻特效密集时的 CPU 和资源加载压力。
- **完善离席轮选。** 保留真人优先与二十人分组规则，修复策略阶段离席后的 AI 代选及后续机变候选处理。

## 上游 Dev 同步

本轮并入 29 个上游提交，主要包括 Bot 每回合自主阵容计划、终局攻势中卢西恩与铳的路线建模、
杰西卡相关候选策略，以及开发环境的外部 AI / LLM 计划、超时和适配器修正。
外部 AI 继续遵循现有开发功能门禁。二十人容量、固定分组、并行轮选与私人自选库存规则继续保留。

## 验证与已知边界

- 四版本各两个自选编队 matches 场景按本分支库存规则重录；默认 golden 及历史版本对应场景通过。
- 最新渲染与档位定向回归 466 项通过，Edge 渲染与设置回归 38 项通过；资源、语音与素材回退扩展回归
  245 项通过。setup、smoke、guards、lint、imports、typecheck 检查通过。
- 全量回归曾发现的 11 项失败已在合并前基线复现，包括布局静态断言、P2P 登记、Windows 符号链接权限
  和可选教程图片缺项；本轮没有把全量测试报告为全绿。
- 低档粒子比例与预算属于 `[ASSUMED]` 工程默认，预算是软准入值；本轮未完成真实手机温升、续航或
  二十名真人压力验收。局部性能采样不代表所有设备的整场帧率提升。
- 三名新干员和三套代表时装已验证实际技能表现；其余已安装时装完成索引与文件核验，尚未逐套实战验收。
  山「硬派速度」两项缺少官方提取目标的映射按现有规则回退基础特效。

已有页面请在更新后刷新；已预缓存资源的客户端需等待缺失资源补齐。
自行部署时须同时更新对应素材和本地索引。仓库不包含提取的游戏素材，本次也没有上传素材附件。
